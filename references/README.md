# References 导航

这个目录把“怎么说”“为什么这么说”和“证据从哪里来”分开保存，避免把用户校准样本误写成兔娘本人的原话，也避免原始调研直接控制每一轮对话。

## 读取顺序

| 任务 | 首选文件 | 用途 |
|---|---|---|
| 日常聊天、读弹幕、接梗、安慰或轻度调戏 | [dialogue-playbook.md](dialogue-playbook.md) | 对话节奏、模式切换、正反例与回归样本 |
| 解释判断依据、分析人设或扩展能力边界 | [synthesis.md](synthesis.md) | 六个心智模型、十条启发式、价值观与局限 |
| 核查公开事实、经历、原话或时间点 | [research/](research/) | 六维原始调研、专项补充与证据分级 |

普通对话不需要遍历整个目录。只有用户问到现实人物事实、近期活动、具体争议或证据来源时，才按主题读取相应研究文件。

## 证据分级

从强到弱依次使用：

1. 本人公开账号、本人明确陈述、可核验的官方活动记录；
2. 有上下文的直播录屏、长对话或可靠媒体转述；
3. 第三方切片、观众评价与标题摘要；
4. 基于多份材料的模型推断；
5. 用户提供的风格校准样本。

第五级可以决定这个 Skill “怎样回答更像用户认识的兔娘”，但不能证明现实中的她说过某句话。涉及私人履历、关系、合同、收入、医疗或未公开生活时，不从弱证据补全。

## 维护规则

- 调整聊天效果：先改 `dialogue-playbook.md`，确认后再同步 `SKILL.md` 中的最小运行规则。
- 新增公开材料：放入对应的 `research/0X-*.md`，记录来源类型、日期与不确定性，再判断是否更新 `synthesis.md`。
- 新增用户测试句：标注为“用户校准”或“合成测试”，不可混入本人语料。
- 模型、启发式数量或命名变化时，同时检查 `SKILL.md`、`README.md`、`FIDELITY.md` 和 `synthesis.md`。
- 近期事实一律重新检索；当前研究材料截止于 2026-08-24。
