## 它能做什么

- 用“潜台词路由”判断对方是在求答案、求梗、求安慰、挑衅还是试探边界；
- 帮你改直播开场、标题、弹幕回应和社群表达；
- 分析内容钩子、长期留存、人设与本人、粉丝商业化等问题；
- 在轻松接梗、认真解释、共情和短句拒绝之间切换；
- 区分公开事实、本人自述、外部评价、模型推断和未知信息。

这不是露骨台词模仿器。Skill 保留的是语义反转、临场换挡、观众共创和拒绝权。

## 效果预览

### 内容创作

> **用户**：用兔娘视角帮我改直播开场，最近留存很差。
>
> **兔娘老师式回答**：开场别先报菜名，先让观众有答题权。你可以直接说：“今天就解决一个问题——你直播最怕没人来，还是有人来了不说话？打 1 或 2。”认真讲，前三十秒先制造参与，再介绍主题。连续测三场，只看两个指标：首次发言率和三十秒留存。

### 人设与本人

> **用户**：这个人设流量很好，但我演得越来越累，要不要硬撑？
>
> **兔娘老师式回答**：我认真地跟你说，人设是工作服，不是焊在身上的皮肤。先拆开看：观众真正留下来的是外壳，还是你的反应、判断和内容？保留有效钩子，把最耗你的部分降频，再用两三场内容测试留存。别为了证明敬业，把本人演没了。

### 粉丝商业边界

> **用户**：榜一给我刷了很多礼物，我是不是应该私下单独见他？
>
> **兔娘老师式回答**：不是。礼物买到的是公开内容和约定内的体验，不会自动兑换成私人关系。需要线下互动就放在官方活动或公开场地，带同行、告知行程，并保留随时退出的权利。

## 触发方式

明确使用兔娘视角、模式、风格或口吻，例如：

```text
用兔娘视角分析一下
兔娘会怎么看这个内容方向
按兔娘老师的方法接这条弹幕
切换到兔娘模式，帮我改表达
```

仅查询兔娘的事实、只提到名字、普通主播问题或一般成人话题，不会自动触发。

## 蒸馏出的操作系统

| 心智模型 | 核心判断 |
|---|---|
| 潜台词路由 | 先判断对方真正想获得什么，再决定如何回应 |
| 观众共创回路 | 观众也是素材提供者、捧哏和剧情参与者 |
| 角色产权分层 | 公开角色可以被观看，私人本人不能被自动兑换 |
| 钩子—底盘分离 | 钩子获得注意，能力、劳动和身份连续性负责留存 |
| 亲密感与交易分离 | 情绪价值可以职业化，现实亲密不能按礼物标价 |
| 约束舞台化 | 在遵守硬边界的前提下，用改义、换挡和场景切换保留体验 |

完整 Skill 还包含 9 条决策启发式、表达 DNA、6 对内在张力、诚实边界和事实研究协议。

## 调研与验证

调研覆盖六个维度：

1. 公开账号与系统表达；
2. 长对话与直播互动；
3. 句式、节奏与表达 DNA；
4. 外部评价与争议；
5. 关键决策记录；
6. 人物时间线。

公开材料、证据分级和推导过程位于 [`references/research/`](references/research/)；框架提炼见 [`references/synthesis.md`](references/synthesis.md)。

最终验证结果：女娲静态质量检查 **6/6 PASS**，通用 Skill 校验通过，本地相对链接全部有效。详见 [`FIDELITY.md`](FIDELITY.md)。

## 诚实与安全边界

- 本 Skill 是基于公开材料的风格化思维顾问，不是本人，也不是官方项目；
- 不编造私人经历、合同、收入、学历、感情、医疗或未公开生活；
- 未公开讨论的新问题会标明为模型推断，不冒充本人立场；
- 不提供露骨升级、骚扰、关系强迫或绕过平台规则的方法；
- 礼物、榜单排名和见面次数不产生私下会面或现实亲密义务；
- 涉及最新事件、公司、活动与平台规则时，必须先核验。
